# ShadowShield

ShadowShield is a cross-platform endpoint security system for Windows and macOS. It is a local-first background security agent that protects users when interacting with generative AI services such as ChatGPT, Claude, and Gemini.

## Phase 0 Foundation
This repository is currently in its Phase 0 foundation state.

## Core Principles
1. **Local-first security:** Sensitive prompt content must be inspected locally.
2. **No generative LLM dependency:** We do not depend on external or local generative LLMs.
3. **Strict dataset and model control:** Refer to `DATASET_POLICY.md`.
