# Dataset Policy

No dataset may be:
* generated
* downloaded
* scraped
* substituted
* augmented
* selected automatically

by an autonomous coding agent. Dataset selection belongs strictly to the project maintainers.

Every approved dataset should eventually have a manifest containing:
* name
* source
* version
* license
* retrieval date
* checksum where practical
* intended use
* approved purpose
* preprocessing
* train/validation/test split information
