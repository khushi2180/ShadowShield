# Privacy Policy

ShadowShield operates under the following privacy principles:

1. **Prompt inspection happens locally:** Content is not sent to external APIs for inspection.
2. **Raw prompt content is transient by default:** We do not store or persist sensitive prompts automatically.
3. **Raw sensitive content should not enter telemetry by default:** Only privacy-preserving metadata is collected.
4. **Security events should prefer metadata:** e.g., AI service, detection category, risk level.
5. **Dataset/model usage requires explicit approval.**
6. **Future diagnostic logging must avoid sensitive content.**
